# 2026-07-30 학습 기록

## 오늘 배운 내용

- 스택은 마지막에 들어온 데이터가 먼저 나오는 LIFO 구조이다.
- 배열의 0번 인덱스부터 데이터를 차례대로 저장한다.
- `topIndex`는 현재 스택의 가장 위에 있는 데이터 위치를 가리킨다.
- 빈 스택의 `topIndex`는 `-1`이고 데이터 개수는 `topIndex + 1`이다.
- `push`는 `topIndex`를 증가시킨 뒤 데이터를 저장한다.
- `pop`은 `topIndex` 위치의 데이터를 처리한 뒤 인덱스를 감소시킨다.
- 배열의 값을 실제로 지우지 않아도 `topIndex`를 내리면 제거된 것으로 처리된다.

## 직접 구현한 기능

- `isEmpty()`
- `isFull()`
- `push()`
- `pop()`
- `peek()`
- `size()`

## 헷갈렸던 점

- `topIndex`가 현재 가장 위의 데이터 위치인지 다음 빈 공간인지 구분해야 한다.
- 스택 클래스는 데이터를 관리하고, 입력과 출력은 `main()`에서 담당하도록 역할을 나눈다.
- C++ 파일은 C 컴파일러인 `clang`이 아니라 `clang++`로 빌드해야 한다.
