## 매일 공부하는 순서

1. 작업을 시작하기 전에 원격 저장소의 최신 내용을 받습니다: `Pull`
2. CLion에서 코드를 작성하고 실행합니다.
3. `study-notes` 폴더에 오늘 배운 내용을 간단히 정리합니다.
4. 변경 내용을 하나의 기록으로 저장합니다: `Commit`
5. 저장한 기록을 GitHub에 올립니다: `Push`
