# Stack

## 핵심 개념

- 마지막에 들어온 데이터가 먼저 나오는 LIFO 구조
- 삽입 연산: `push`
- 삭제 연산: `pop`
- 가장 위의 데이터 확인: `peek`
- 배열 기반 구현에서는 `topIndex`로 가장 위의 데이터 위치를 관리
